 Iris Dataset  Exploratory Data Analysis (EDA)

This project performs Exploratory Data Analysis (EDA) on the Iris dataset using Python, Pandas, NumPy, Matplotlib, and Seaborn.

 Objectives
- Analyze dataset structure and summary statistics.
- Identify missing values, duplicates, and potential outliers.
- Create visualizations to understand feature distributions and correlations.
- Identify insights that can improve machine learning classification.

 Key Findings
The dataset contains three equally represented Iris species. Petal length and petal width show strong relationships with species, making them useful features for classification. The analysis also identifies potential data-quality issues for further investigation.

 Tools I Used
Python, Pandas, NumPy, Matplotlib, Seaborn, and Jupyter Notebook.
